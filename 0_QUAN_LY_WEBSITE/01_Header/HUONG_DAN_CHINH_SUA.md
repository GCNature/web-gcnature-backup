# 📌 QUẢN LÝ PHẦN HEADER (THANH ĐẦU TRANG)

Phần Header nằm ở vị trí trên cùng của tất cả các trang web GCnature.

## 📂 Các thành phần chính trong Header:
1. **Logo thương hiệu GCnature**:
   - Vị trí file ảnh logo: `public/logo.png` và `public/logo-xanh.png`
2. **Thanh tìm kiếm sản phẩm**:
   - Hỗ trợ tìm kiếm theo tên sản phẩm, từ khóa mỹ phẩm.
3. **Menu điều hướng**:
   - Trang chủ, Catalog sản phẩm, Khuyến mãi, Blog tin tức, Tuyển dụng, Liên hệ.
4. **Nút Giỏ hàng, Đăng nhập, Đổi ngôn ngữ (Việt / Anh)**.

## 💻 Mã nguồn liên quan (Dành cho kỹ thuật/Coder):
- Component giao diện: `src/components/Header.tsx`
- Menu tìm kiếm gợi ý: `src/components/CategorySuggestions.tsx`
- Đổi ngôn ngữ: `src/components/LanguageSwitcher.tsx`
