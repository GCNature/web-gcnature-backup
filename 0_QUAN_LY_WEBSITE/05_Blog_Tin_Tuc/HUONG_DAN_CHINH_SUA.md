# 📌 QUẢN LÝ BLOG TIN TỨC & BÀI VIẾT

Thư mục quản lý các bài viết chăm sóc da, tin tức sắc đẹp và kiến thức mỹ phẩm Hàn Quốc.

## 📂 Các trang bài viết:
1. **Trang danh sách Tin tức**: `src/pages/News.tsx`
2. **Trang chi tiết bài viết**: `src/pages/NewsDetail.tsx`
3. **Khối tin tức nổi bật ở trang chủ**: `src/components/NewsSection.tsx`

## 💻 Quản trị Admin:
- Thêm/Sửa/Xóa bài viết & tải ảnh bài viết: `src/pages/admin/AdminArticles.tsx`
- Bảng CSDL lưu trữ: Bảng `articles` trong MySQL database.
